# SI7011-DeepLearning-Talleres
Talleres de la materia SI7011-DeepLearning

### Taller 1 – Deep Neural Networks (DNNs)
Implementación de **redes neuronales densas (MLP)** en PyTorch.  
Se trabaja la transición desde regresión logística hacia redes profundas.

### Taller 2 – Convolutional Neural Networks (CNNs)
Aplicación de **redes convolucionales** para clasificación de imágenes en Tiny ImageNet.  
Se enfoca en el aprendizaje de representaciones espaciales.

### Taller 3 – RNNs para series de tiempo
Implementación de **RNNs/LSTMs** para modelar dependencias temporales en datos secuenciales.

### Taller 4 – Transformers para NLP
Uso de **Transformers** para tareas de procesamiento de lenguaje natural.
